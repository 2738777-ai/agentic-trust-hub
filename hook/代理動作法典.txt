# 代理動作法典（白話版）——真的 AI 代理（例如 Claude Code）要連網、要把東西送出去之前，過這張表
# 綠、黃＝插座不出聲，照代理原本的權限流程走（黃只記一筆）；待審＝停下來問人；拒＝不准做
# 跟攻防台的動作關卡同一個想法，但這是給真實代理用的：寫程式的代理本來就常自己去查文件，不能每次都擋

尺：綠 < 黃 < 待審 < 拒
合成：最壞的贏
讀不到結果：拒

# 誰要它連這個網址：看對話紀錄，這個網址最早出現在哪裡
發起者檢查 說 使用者本人 → 綠
發起者檢查 說 代理自己想的 → 黃
發起者檢查 說 讀到的內容 → 待審
發起者檢查 說 查不到紀錄 → 待審

# 送去哪：允許清單上的網域、或根本不連外
目的地檢查 說 不連外 → 綠
目的地檢查 說 表上有 → 綠
目的地檢查 說 表上沒有 → 黃
目的地檢查 說 怪地址 → 待審

# 帶了什麼：金鑰、密碼、私鑰、存祕密的檔案，永遠不准跟著出門
內容檢查 說 沒有祕密 → 綠
內容檢查 說 有祕密 → 拒
