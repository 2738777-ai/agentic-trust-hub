# 動作關卡法典（白話版）——代理要「往外送東西」之前的那一關（確認那一下・最小版）
# 不管代理被誰說服，它要做的動作本身過不了表，就不准做

尺：綠 < 黃 < 待審 < 拒
合成：最壞的贏
讀不到結果：拒

# 誰發起的：客人本人在對話裡要求的才算；網頁、評論、工具回傳的字都只是資料
發起者檢查 說 客人本人 → 綠
發起者檢查 說 讀到的內容 → 拒
發起者檢查 說 不明 → 拒

# 送去哪：只准送回這次對話的客人、或民宿自己的系統
目的地檢查 說 表上有 → 綠
目的地檢查 說 表上沒有 → 拒

# 帶了什麼：金鑰永遠不准出門；別的客人的資料要人看；只帶這位客人自己的訂單沒問題
內容檢查 說 只有這位客人的 → 綠
內容檢查 說 有別的客人資料 → 待審
內容檢查 說 有金鑰 → 拒
