# 民宿伺服器法典（白話版）——跟萬用插座同一個翻譯器、同一個判決引擎
# 只有照正常流程來的才放行，表上沒寫的一律不准

尺：綠 < 黃 < 待審 < 拒
合成：最壞的贏
讀不到結果：拒

# 方法：看檔案、看首頁可以；客人可以寫評論；其他寫入一律不准
方法檢查 說 只讀 → 綠
方法檢查 說 寫評論 → 綠
方法檢查 說 其他寫入 → 拒

# 路：只認表上這幾條（首頁、公開檔案、評論）
路由檢查 說 表上有 → 綠
路由檢查 說 表上沒有 → 拒

# 檔案：解碼到底、捷徑追到底，必須落在公開資料夾裡
路徑檢查 說 在房間內 → 綠
路徑檢查 說 走出房間 → 拒
路徑檢查 說 怪字元 → 拒
路徑檢查 說 不用檔案 → 綠

# 評論：發表前轉到側面看（用萬用插座的側面掃描），人看不到的字不准上架
評論側面 說 綠 → 綠
評論側面 說 黃 → 黃
評論側面 說 待審 → 待審
評論側面 說 拒 → 拒
評論側面 說 不是評論 → 綠
