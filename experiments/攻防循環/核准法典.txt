# 核准法典（白話版）——「確認那一下」：有人按「好」、系統要發出通行證之前，過這張表
# 被騙的核准，鑰匙本身是合法發出的；換鑰匙沒用，要修的是這一道門

尺：綠 < 黃 < 待審 < 拒
合成：最壞的贏
讀不到結果：拒

# 發起申請的，和按「好」的，是不是同一條繩（同一個人、同一個對話）
發起者對照 說 同一條繩 → 綠
發起者對照 說 對不上 → 拒
發起者對照 說 查不到 → 拒

# 申請的用途在不在表上
用途檢查 說 在表上 → 綠
用途檢查 說 不在表上 → 拒

# 主人看到的內容，跟真的要發出去的，是不是同一份（指紋比對）
指紋檢查 說 一致 → 綠
指紋檢查 說 不一致 → 拒
