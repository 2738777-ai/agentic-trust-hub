# 伺服器門口法典（白話版）——跟萬用插座同一個翻譯器、同一個判決引擎，只換這張表
# 精神：只有照正常流程來的才放行，表上沒寫的一律不准（不是列出壞的，而是只列好的）

尺：綠 < 黃 < 待審 < 拒
合成：最壞的贏
讀不到結果：拒

# 方法檢查：這台伺服器只給人讀檔，不給人寫
方法檢查 說 只讀 → 綠
方法檢查 說 想寫入 → 拒

# 路由檢查：只認表上這幾條路，其他路（例如 /admin）一律不准
路由檢查 說 表上有 → 綠
路由檢查 說 表上沒有 → 拒

# 路徑檢查：把檔名解碼到底、算出真正落點（連捷徑都追到底），必須在「公開資料夾」裡面
路徑檢查 說 在房間內 → 綠
路徑檢查 說 走出房間 → 拒
路徑檢查 說 怪字元 → 拒          # 解碼解不乾淨、空字元、反斜線……看不懂就當壞
路徑檢查 說 不用檔案 → 綠        # 首頁這種不碰檔案的路

# 守衛代理：會讀請求內容、會判斷的 AI。它只能「加嫌疑」，不能「減嫌疑」——
# 它說放行只算綠，蓋不掉別人說的拒（最壞的贏）。它會被騙，所以不給它最後一句話。
守衛代理 說 正常 → 綠
守衛代理 說 放行 → 綠
守衛代理 說 可疑 → 待審
